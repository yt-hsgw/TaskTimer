# 077 右ペインをインライン編集中心の詳細ビューへ再設計する

GitHub Issue: #189

## 背景

右ペインは、参照サマリー、折りたたみ編集、リスト色継承、タグ管理など複数の操作概念が混在している。実務利用では、詳細を読みながら変更したい箇所だけをその場で編集できる方が迷いにくい。

## 仕様

- 通常時は表示専用に見える詳細ビューを基本にする。
- 編集可能な項目は、対象箇所をクリックすると編集状態になる。
- ホバー時だけ表示される操作や、ホバーで強く見た目が変わる編集導線は置かない。
- フォーカスが外れたら保存する。
- 空白タイトルや空白タグ名は保存せず、編集前の値へ戻す。
- タイトル下のサマリーカードは廃止する。
- セクション折りたたみは廃止する。
- 表示順は、タイトル、タグ、所属リスト、タスク表示色、期限、目標時間/繰り返し、サブタスク、メモ、削除とする。
- サブタスク追加は最終的に共通ダイアログへ寄せる。ただし最初の実装スライスでは既存作成Use Caseを維持し、詳細内フォームからポップアップ化する。

## 実装分割

1. 詳細ビューの構造をインライン編集前提へ変更する。
   - タイトルをクリック編集、フォーカスアウト保存にする。
   - メモをクリック編集、フォーカスアウト保存にする。
   - タイトル下サマリーと折りたたみセクションを廃止する。
   - サブタスク一覧を常時表示する。
2. タグ編集をチップ末尾入力へ変更する。
   - 既存タグ選択と新規タグ作成を同じ入力導線にする。
   - 新規タグ作成とタスク付与を同じミューテーション導線にする。
   - 既存タグ候補を明示的に表示する。
   - タグ追加入力はEnterまたはフォーカスアウトで保存する。
   - 設定済みタグ押下でタグ名を編集し、同じタグを使う他タスクにも変更を反映する。
   - タグ入力またはタグ名編集中は下線だけで編集状態を示し、タグ名編集中は追加導線を表示しない。
   - タグ自体の削除は通常の詳細編集から外し、必要時は専用のタグ管理UIで扱う。
3. 所属リスト、目標時間、繰り返し、サブタスク追加をポップアップ編集へ寄せる。
   - 所属リストはselectではなく、現在リストを押してリスト候補ポップアップを開く。
   - リスト候補はリスト色と名前を表示し、選択時に既存のタスク更新Use Caseで保存する。
   - フォーカスアウト保存とポップアップ内クリックが競合しないようにする。

## 設計理由

- 既存のApplication Use CaseとRepository境界は、タスク/サブタスク更新、タグ操作、サブタスク作成を既に持つため、最初のスライスではDB境界を増やさない。
- タイトルとメモはユーザーが頻繁に編集するため、最初にインライン編集の共通挙動を固める。
- サブタスク追加やタグ作成は複数Use Caseが絡むため、UI構造変更後の別スライスで扱う。

## トレードオフ

- 一度に全項目をインライン化しないため、Issue #189の最終形までは複数PRになる。
- 先に折りたたみを廃止すると右ペインの縦方向は長くなるが、各項目の位置が固定されて迷いにくくなる。

## 代替案

- 右ペインを全面的に作り直す。
  - 最終形へ近づくが、タグ、期限、繰り返し、サブタスク、削除の回帰範囲が広すぎるため採用しない。

## 危険ケース

- フォーカスアウト保存が詳細を閉じる操作と競合する。
- 空白タイトルが保存され、Application検証エラーで画面だけ不整合になる。
- メモ本文をHTMLとして描画してしまう。
- タイトルやメモ本文をテストログ、エラー、計測ログへ出してしまう。
- サブタスク一覧を常時表示して、大量サブタスクで右ペインが重くなる。

## 受け入れ条件

- タイトルをクリックすると入力になり、フォーカスアウトで保存される。
- 空白タイトルは保存されず、編集前のタイトルへ戻る。
- メモをクリックするとtextareaになり、フォーカスアウトで保存される。
- 編集導線はクリックとキーボードフォーカスで成立し、ホバー時のアクション表示に依存しない。
- 親タスク詳細のタグ欄はチップ末尾から既存タグ付与または新規タグ作成 + 付与ができる。
- タグ追加時は既存タグ候補が表示され、Enterまたはフォーカスアウトで保存される。
- 設定済みタグの名前部分を押すとタグ名を編集でき、Enterまたはフォーカスアウトで保存される。
- タグ入力またはタグ名編集中は下線だけで編集状態が示され、タグ名編集中は `タグを追加` が表示されない。
- 親タスク詳細の所属リストは現在値をクリックすると候補ポップアップが開き、選択時に保存される。
- 所属リスト候補にはリスト色とリスト名を表示し、Escapeまたはフォーカスアウトで閉じる。
- サブタスク詳細では親タスクのタグを継承表示し、タグ入力は表示しない。
- タイトル下の現在情報サマリーが表示されない。
- `タスクを編集` と `サブタスク` の折りたたみボタンが表示されない。
- サブタスク一覧は親タスク詳細で常時確認できる。
- メモ本文はReactテキストとして描画され、HTMLとして解釈されない。
