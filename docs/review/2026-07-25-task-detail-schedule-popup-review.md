# タスク詳細 目標時間/繰り返しポップアップ レビュー

対象: GitHub Issue #189 / `docs/issues/077-task-detail-inline-redesign.md`

## 判断

フォローアップ付き承認。

## 指摘事項

- 目標時間/繰り返しは既存のタスク/サブタスク更新Use Caseを使い、Application/Repository境界を増やさない。
- 目標時間はプリセットのドロップダウンで選択する。
- 保存ボタンは置かず、Enterまたはフォーカスアウトで保存する。Escapeでは保存せず現在値へ戻す。
- ポップアップ内のチェックボックス、select、入力操作中はblur保存で閉じない。
- 繰り返し有効化時に期限が未設定の場合は、既存仕様どおり今日の期限を補完する。

## 破綻シナリオ

- ポップアップ内クリックでフォーカスアウト保存が先に走ると入力途中で閉じるため、ポップアップ内のポインター操作中は保存を保留し、フォーカス移動先を確認する。
- Escapeで閉じた直後にblur保存が走るとキャンセルできないため、Escapeではdraftを現在値に戻して閉じる。
- 目標時間に無効値を入れた場合は既存の入力変換とUse Case検証に委ねる。

## スケール懸念

- 追加Queryや一覧再取得範囲は増やさない。既存の詳細ミューテーション範囲に収める。

## セキュリティ懸念

- 数値、select、checkboxのみを扱い、ユーザー入力HTMLは描画しない。
- アプリ実行時の外部通信、追加権限、秘密情報の保存はない。

## テスト不足

- 実機でポップアップ内のselect操作、Tab移動、Escapeキャンセルが期待通りか確認が必要。
