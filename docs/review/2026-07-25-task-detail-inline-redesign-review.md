# タスク詳細インライン編集基礎スライス レビュー

対象: GitHub Issue #189

## チェックリスト確認

- 仕様: `docs/issues/077-task-detail-inline-redesign.md` と `docs/ui-ux-redesign.md` に記録した。
- 設計: 既存のタスク/サブタスク更新Use Caseを使い、右ペインPresentationだけを局所編集へ寄せる。
- トランザクション境界: タイトル、メモ、目標時間/繰り返しは既存 `UpdateTask` / `UpdateSubtask` の境界を使う。
- 外部通信: 追加しない。

## 指摘事項

- タグのチップ末尾入力、新規タグ作成と即時付与の一貫性、サブタスク追加ダイアログ化は後続スライスに残す。
- 目標時間/繰り返しはまだ保存ボタン付きの局所編集で、完全なフォーカスアウト保存ではない。

## 破綻シナリオ

- タイトル編集中に詳細を閉じた場合、フォーカスアウト保存と閉じる処理が競合する。
- 空白タイトルを保存しようとして、Application層エラーとUI表示がずれる。
- メモの巨大入力で右ペインのスクロールが極端に長くなる。

## スケール懸念

- サブタスク一覧は常時表示になったため、サブタスクが非常に多い親タスクでは右ペイン描画が重くなる可能性がある。
- 既存Read Model内の選択タスク配下だけを描画しており、全タスクのサブタスク走査は追加していない。

## セキュリティ懸念

- タイトルとメモはReactテキストとして描画し、HTMLとして解釈しない。
- タイトルやメモ本文をログ、計測結果、エラーへ出さない。
- 新しいTauri権限、OS権限、外部通信は追加しない。

## テスト不足

- 実機でフォーカスアウト保存と閉じる操作の競合確認が必要。
- タグ入力とサブタスク追加ダイアログ化は未対応。

## 判断

フォローアップ付き承認。右ペインの構造をインライン編集前提へ寄せる基礎としては妥当。#189完了には、タグ編集、リスト選択ポップアップ、目標時間/繰り返しポップアップ、サブタスク追加ダイアログ化の追加スライスが必要。
