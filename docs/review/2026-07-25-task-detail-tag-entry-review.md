# タスク詳細タグ入力 レビュー

対象: GitHub Issue #189 / `docs/issues/077-task-detail-inline-redesign.md`

## 判断

フォローアップ付き承認。

## 指摘事項

- タグ名変更とタグ自体の削除は今回の詳細ビューから外した。必要であれば、右ペインの通常編集ではなく専用のタグ管理UIとして再設計する。
- 新規タグ作成とタスク付与は、Presentationから既存Tauriコマンドを順に呼ぶ。Application/Repository境界は増やさないため、完全なDB単一トランザクションではない。

## 破綻シナリオ

- `createTag` 成功後に `attachTagToTask` が失敗すると、タグだけが残る。画面上はミューテーション失敗として扱い、次回タグ候補に残るため再付与できる。
- 既に付与済みのタグ名を再入力した場合、重複付与せず入力を戻す。
- サブタスク詳細では親タスクのタグを継承表示するだけにし、サブタスクから親タスクのタグを誤変更しない。

## スケール懸念

- タグ候補は `tags` Read Modelをそのまま `datalist` に渡す。タグ数が大幅に増えた場合は検索型ポップアップへ切り替える。

## セキュリティ懸念

- タグ名はReactテキストと `datalist` valueとして扱い、HTMLとして描画しない。
- アプリ実行時の外部通信、追加権限、秘密情報の保存はない。

## テスト不足

- 実機で日本語IME入力中のEnter確定とタグ追加の衝突確認が必要。
- 大量タグ時の候補表示は未確認。
